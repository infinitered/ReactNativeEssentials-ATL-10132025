## Workshop Overview

This workshop is designed to help React developers transition to mobile development while highlighting the similarities between web and mobile platforms. Each chapter builds upon the previous one, creating a complete React Native application.

### What You'll Learn

- **Debugging**: Master React Native debugging tools and techniques
- **Visual Design**: Create beautiful, consistent UIs with design systems
- **Navigation**: Implement comprehensive navigation with Expo Router
- **Data Handling**: Work with lists, APIs, and data management
- **Theming**: Create adaptive themes that respond to system preferences
- **Accessibility**: Build inclusive apps for all users
- **Testing**: Implement comprehensive testing strategies

### Prerequisites

- Basic knowledge of React and JavaScript
- Node.js and npm/yarn installed
- iOS Simulator (macOS) or Android Emulator
- Code editor (VS Code recommended)

### Getting Started

1. **Environment Setup**: Run the environment verification script
   ```bash
   pnpm run verify-environment
   ```

2. **Project Setup**: Install dependencies and configure the project
   ```bash
   pnpm run setup
   ```

3. **Start Development**: Begin with the first chapter
   ```bash
   pnpm start
   ```
